# Тестове завдання

Створити двосторонній зв’язок між двома модулями на будь-якій частоті, модуляція LoRa SW6, BW800

Передавати пакети не менше 10 байт, заповнення пакетів, забезпечити також контроль цілісності пакетів

RF Модулі SX1280, мікроконтролер STM32F401CCU6

Використати STM32CubeIDE

# Параметри зв'язку

## SetModulationParams
- Модуляція: LoRa
- Spreading Factor: 6
- Bandwidth: 812.5 кГц
- Coding Rate: 4/5

## SetPacketParams
- Preamble Length: 12 байт
- Header Type:     EXPLICIT_HEADER  (0x00)
- Payload Length:  11 байт
- CRC:             LORA_CRC_DISABLE (0x00)
- IQ:              LORA_IQ_STD      (0x40)

## Frequency
2404000000 Hz

## Пакет
Корисне навантаження 10 байт + байт контрольної суми. Всього 11 байт

## CRC
Використано CRC8 від CRSF (Crossfire) протоколу

# Алгоритм роботи
Модулі стартують у режимі RX. Очікується натискання кнопки KEY на шилді. Після натискання кнопки відбувається перехід в режим TX та передача пакета ( + "підмогування" світлодіодом на PC13 ). Відповідно, на іншому шилді у разі прийому пакета та збігу контрольної суми також відбувається "підморгування" світлодіодом. Алгоритм працює в обидві сторони.

# Стенд для програмування
Використано два ST LINK V2 та створено дві Debug-конфігурації (у CubeIDE) що дозволяє працювати з обома шилдами одночасно
